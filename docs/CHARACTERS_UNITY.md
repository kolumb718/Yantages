# Персонажи в Unity

В Ship подключены текущая героиня из courier-girl-v07-hair.blend и сова из space-owl-v01.blend. Кубический персонаж заменён на модель; управление сохраняется. Сова парит рядом и мгновенно переносится между палубами при использовании лифта.

## Ассеты и импорт

- unity/Assets/Art/Characters/CourierGirl/ — FBX, JSON с палитрой, материалы Standard и prefab; рост героини 1,78 м.
- unity/Assets/Art/Characters/SpaceOwl/ — соответствующие ассеты совы; игровой рост 0,48 м.
- tools/blender/export_unity_characters.py — воспроизводимый экспорт из открытого courier-girl-v07-hair.blend, в котором сохранена и сцена совы. Модификаторы и кривые запекаются, скрытые предыдущие глаза/волосы и студия исключаются. Исходная геометрия Blender не меняется.
- CharacterSetup.cs создаёт материалы и prefab, нормализует размер, размещает ноги у корня и записывает ссылки в компонент CourierCharacters сцены Ship. GUID существующих ассетов при повторной подготовке сохраняются.

Меню Unity: Orbita → Prepare character prefabs. Редактор должен быть вне Play Mode; все открытые сцены должны быть сохранены. При первом импорте без prefab подготовка выполняется автоматически, если нет несохранённых сцен.

CourierCharacters.cs отвечает за создание моделей и следование совы. CourierShip сохраняет движение, границы палуб, лифт, терминал и заказ. Сцена Ship содержит сериализованные ссылки на оба prefab: загрузка через AssetDatabase во время игры не требуется.

## Ограничения

Это статические модели: нет рига, ходьбы, движений крыльев и физики волос. Парение совы — движение всего объекта. Сова v01 пока без запрошенного ранее космического шлема. Героиня содержит 145 645 треугольников после запекания волос; сова — 668. Перед игровым производством нужны оптимизация героини и анимации. Player-сборка и WebGL отдельно не проверены.

## Повторная проверка

Editor-скрипт CharacterIntegrationCheck.Run предназначен только для отдельного batch-запуска Unity с графическим устройством, без -nographics и без -quit. Он сам завершает процесс после проверки. Не запускать на занятом другим редактором checkout; для проверки использовалась копия проекта в .local/unity-character-check/.

Проверка вызывает те же методы движения и взаимодействия, которые использует Update, затем проверяет обе палубы, перенос совы, доступность терминала и повторный Play Mode. Кадры сохраняются в Captures/ проверяемого проекта. Это программная проверка логики и визуального импорта; она не заменяет ручную проверку клавиатуры или player-сборку.

## Результат 24 октября 2026

Unity 6000.6.7f1, Windows, Built-in renderer: проверка завершена с кодом 0 и ORBITA_CHARACTER_CHECK_PASS. Масштаб, материалы, движение, диагональ, границы, обе палубы, следование совы, терминал и повторный Play Mode прошли. Из копии в основной проект перенесены проверенные prefab, материалы, их .meta и сцена; исходные GUID сохранены.
