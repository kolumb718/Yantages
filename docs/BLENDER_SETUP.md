# Blender и MCP

Настроено 24 октября 2026 года.

## Конфигурация
- Blender 5.2.3 LTS: C:\Program Files\Blender Foundation\Blender 5.2\blender.exe.
- Сервер mcp-for-blender 2.2.4 установлен из PyPI в .local/blender-mcp-env.
- Аддон blender_mcp.py установлен и включён в пользовательском Blender 5.2, настройки сохранены.
- Проверенный protocol version: 15; версия аддона: 1.8.
- Аддон слушает 127.0.0.1:9876; MCP-сервер использует stdio, его запускает клиент.
- Codex-конфигурация: .codex/config.toml, секция mcp_servers.blender. Unity MCP сохранён без изменений.
- Телеметрия отключена через DISABLE_TELEMETRY=1, согласие аддона — false. Облачные генераторы и библиотеки отключены, ключи API не добавлялись.

Официальный репозиторий интеграции: https://github.com/ahujasid/mcp-for-blender.
Это сторонний проект, не интеграция Blender Foundation.

## Повторный запуск
1. Открыть Blender 5.2.3. Аддон запускает локальное соединение автоматически.
2. Если подключения нет: боковая панель 3D View → N → MCP for Blender → Connect/Start MCP Server.
3. Открыть доверенный проект Yantages в Codex. После добавления MCP-конфигурации может понадобиться новая сессия или перезапуск клиента.
4. Проверить get_addon_status и get_scene_info. Не запускать второй клиентский сервер для той же сцены одновременно.

Пути в текущей конфигурации относятся к этой машине. На другой машине установить Blender, сервер версии 2.2.4 и аддон, затем изменить путь command.
Локальные инструменты .local не входят в Git. Для восстановления среды использовать uv venv и uv pip install mcp-for-blender==2.2.4, затем команду mcp-for-blender install-addon.
Если каталог аддонов ещё отсутствует, установить BLENDERMCP_ADDONS_DIR в пользовательскую папку Blender 5.2/scripts/addons и создать её. Для корректного вывода кириллицы/стрелок на Windows использовать PYTHONUTF8=1.
После установки включить аддон в Blender; он может быть включён программно через addon_utils.enable с сохранением preferences. Не заменять существующий startup-файл или рабочую сцену.

Проверка выполнена отдельным SDK-клиентом через stdio; автоматическое обнаружение инструментов в новой сессии Codex пока отдельно не проверено.
Моделирование, экспорт и перенос в Unity этим шагом не выполнялись. Blender оставлен открытым с исходной сценой, без сохранения нового .blend.

## Производство ассетов
Исходные .blend хранить в art/, экспорт для игры — в unity/Assets/ с .meta. Резервные .blend1/.blend2 не коммитить.
Перед моделированием проверять активную сцену, несохранённую работу и выделение. Не очищать сцену автоматически при подключении.
Low-poly направление и выбранный концепт сверять с docs/REFERENCES.md. Финальный дизайн пока не выбран.
