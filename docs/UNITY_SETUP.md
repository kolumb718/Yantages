# Unity и локальный MCP

Редактор: Unity 6000.6.7f1 (b22767f04f04).
Проект: W:\Planets\Yantages\unity.
Пакет: CoplayDev MCP for Unity v10.3.0, закреплён в manifest.json; Git SHA закрепляется packages-lock.json.
Сервер: MCP for Unity Server 10.3.0, установлен в локальном .local/mcp-env из официального тега.

Источники: https://github.com/CoplayDev/unity-mcp/tree/v10.3.0 и https://developers.openai.com/learn/docs-mcp.

## Настройка
Unity-проект инициализирован настоящим редактором. Настройки, сцена Ship.unity, пакеты и .meta включаются в Git; Library и локальные инструменты исключены.
Сервер слушает только 127.0.0.1:8080. Телеметрия отключена переменной DISABLE_TELEMETRY и настройкой Unity.
Конфигурация клиента — .codex/config.toml в корне репозитория, endpoint http://127.0.0.1:8080/mcp.
Конфигурация не содержит секретов и не изменяет другие MCP-серверы пользователя. Проектные настройки Codex требуют доверенного проекта.

## Запуск
1. В PowerShell из корня: ./tools/start-unity-mcp.ps1. Не запускать второй сервер, если порт уже обслуживается текущим.
2. Открыть unity/ в Unity Hub.
3. В редакторе: Orbita → Connect local MCP. Можно также использовать Window → MCP for Unity.
4. После изменения конфигурации клиенту Codex может потребоваться новая сессия/перезапуск для обнаружения инструментов. Не считать это выполненным без проверки в клиенте.

На этой машине скрипт использует уже установленный .local/mcp-env. На новой машине при наличии uvx он запускает закреплённый сервер через uvx; uv устанавливается отдельно по инструкции поставщика.
Сервер и редактор должны оставаться запущенными. Автозапуск Windows не устанавливался.
