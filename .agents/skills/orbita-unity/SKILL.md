# Unity-разработка Орбиты

Найти корень репозитория по AGENTS.md и папке unity/. Прочитать docs/TECHNICAL.md и STATUS.md; текущую реализацию сверить с кодом.
Unity — основной движок. До первого импорта не утверждать, что scaffold является проверенным проектом.
При поиске проблем сначала проверить версию редактора, Console и реальный запуск. Не выдумывать точный путь установленного редактора.

Для изменений корабля учитывать две палубы, фиксированную камеру, доступность лифта и терминала. Не переносить в Unity автоматически настройки экспорта Godot.
Сейчас геометрия генерируется в CourierShip.Start, сцена создаётся ProjectSetup. Изменять только нужную часть, а при расширении выделять ответственность по docs/TECHNICAL.md.
Сохранять .meta/GUID, не включать Library, логи и локальные сборки. Новые зависимости добавлять только по конкретной необходимости.

Проверить изменённый игровой сценарий по docs/TESTING.md. Для визуальной правки смотреть настоящую сцену; чтение исходника не заменяет визуальную проверку.
Обновить факты и ограничения в STATUS, а управление — также в GAMEPLAY и unity/README.md, если оно изменилось.
Навык не предоставляет дополнительных разрешений на публикацию или изменение среды.
