# Орбита — корабль курьера

Первый браузерный 3D-прототип на Three.js: корабль-дом на Земле, движение персонажа и интерактивный терминал заказов. Авторские геометрические декорации, боковая перспективная камера, тёплый свет жилой зоны и холодный свет кабины.

Node.js 22.12+ или 24. `npm ci`, затем `npm run dev`. Для сборки: `npm run build`.

Управление: WASD или стрелки, E возле терминала, Escape закрывает заказ. На сенсорных устройствах — экранные кнопки. Звук включается отдельно. Подойдите к светящемуся терминалу в центре и примите заказ. Полёты и получение еды ещё не реализованы.

## Godot 4

Папка `godot/` — версия корабля для Godot 4 с открытой 3D-сценой, движением и терминалом. В Godot выберите **Импортировать**, укажите `godot/project.godot`, затем нажмите **F6** или **F5**. Управление: WASD или стрелки, E у терминала, Escape закрывает заказ. Это отдельный прототип сцены; браузерная версия пока сохранена в корне репозитория.
