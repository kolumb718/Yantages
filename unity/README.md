# Орбита · Unity

Откройте эту папку через Unity Hub → Add project from disk в редакторе Unity 6 LTS.
Выберите шаблон Built-in, если Hub предложит выбрать графический конвейер.
Сцена `Assets/Scenes/Ship.unity` создаётся автоматически при первом импорте.
Нажмите Play. Геометрия интерьера появляется при запуске.

WASD / стрелки — движение, Shift — быстрее, E — терминал или лифт,
Escape — закрыть заказ. Светящаяся площадка перед терминалом ведёт на вторую палубу.

Это первая основа переноса с Godot: два этажа, каюта, гостиная, панорамный мостик,
растения, освещение и заказ. Физика мебели, полёты и получение еды пока не реализованы.
Используется Built-in renderer, Standard shader и классический Input Manager.
При изменении Active Input Handling выберите Input Manager (Old) или Both.

Редактор Unity на машине при подготовке проекта не найден; импорт, компиляция,
визуальная проверка и сборка WebGL ещё не проверены.
